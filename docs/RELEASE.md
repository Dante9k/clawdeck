# 1.0.0-rc.2 交付与验收

状态：发布候选版；部署方完成下列验收后再作为正式版推广。

## 对外定位

ClawDeck 是部署在单台 Linux Docker 主机上的中文 OpenClaw 控制台，用于统一查看容器状态、管理模型/API Key/渠道配置、预览变更和从备份恢复。面向拥有该服务器管理权限的可信管理员。

已覆盖：自动发现、显式接入授权、状态与资源、日志、单项/批量启停、逐实例模型与渠道管理、批量默认模型、原生配置校验、差异预览、备份恢复、并发冲突检测和操作结果追踪。

未覆盖：多服务器、租户隔离、账号/角色/SSO、集中保险库、OAuth 代登录、OpenClaw 自动升级、渠道实时探测、模型计费/额度统计、外部通知、长期监控存储。无需宣传为上述能力。没有替换已有 OpenClaw 管理后台。

## 本次修复

RC.2 额外修复操作编号并发登记、过期后重用、恢复排序与磁盘记录校验，补齐 JSON 媒体类型和 Origin 校验、Docker 请求绝对超时及截断帧拒绝。离线演示改为模块打包，加入格式与静态检查。详见 [变更记录](../CHANGELOG.md)。

1. 模型数组排序按唯一 ID 还原密钥，拒绝无法辨认对应关系的含密钥数组。
2. HTTP 请求缓冲完整字节后解码 UTF-8，拒绝非法编码。
3. 配置读取使用请求代次，旧响应不能覆盖新版本或未保存草稿。
4. 表单只合并实际修改过的字段，保留可选字段缺省语义。
5. 成功执行后的审计失败返回成功和警告；超时等不确定结果明确标为待核对。
6. 容器助手关闭输入后让 stdout 自然排空，避免 Linux 管道输出截断。
7. 操作编号持久去重，重启后的未完成操作不会自动重试。
8. 中文输入法组合输入期间不重建搜索框；保存期间冻结编辑器。

## 安装验收

按 README 执行 `sh scripts/install.sh`，通过 SSH 隧道访问面板。

- [ ] `docker compose ps` 显示面板运行且 HTTP 健康检查通过；默认端口只绑定 127.0.0.1。
- [ ] `.env` 权限 0600，随机密码可以登录；退出后接口需要重新登录。
- [ ] 总览显示真实主机和容器信息，没有「演示模式」。
- [ ] 自动发现但未加 managed label 的容器只能查看状态和日志；直接调用写接口也应拒绝。
- [ ] 给一个测试实例加入 `io.clawdeck.managed: "true"`，重新应用原 Compose；实例自检通过。
- [ ] 记录 Docker、Compose、CPU 架构、OpenClaw 镜像 tag/digest、配置路径和挂载类型。

## 单实例验收

使用可中断的测试实例，先由原部署系统备份其完整状态目录。

- [ ] 模型/渠道读取成功，浏览器响应和操作记录没有明文 API Key。
- [ ] 修改一个非密钥字段；差异准确；取消预览不写入配置。
- [ ] 保存经过原生校验，备份出现；检查实例实际配置和运行效果。
- [ ] 当前镜像若不支持热加载，手动重启后生效；面板不能代替实际调用验证。
- [ ] 选择备份，确认恢复差异；恢复后原配置和凭据可正常工作，其他字段保持当前值。
- [ ] 两个浏览器窗口分别读取同一版本，先保存一个，再保存另一个应提示版本冲突。
- [ ] 将模型列表排序，验证每个模型仍使用对应凭据；不使用生产密钥做此测试。
- [ ] 真实中文账号名称保存后没有乱码；编辑中切换标签、刷新、取消操作不会静默丢失草稿。

## 批量与恢复验收

- [ ] 两个运行中测试实例都已登记相同 provider/model，批量默认模型先预检，再确认差异并依次执行。
- [ ] 一个实例缺少模型登记时，整个批次不开始写入。
- [ ] 执行中人为造成版本冲突，后续实例停止；已经成功项有记录和可恢复备份。
- [ ] 单项/批量启停符合所选实例范围，失败时不继续执行剩余项。
- [ ] 重启 ClawDeck 容器后操作结果保留；未完成项显示待核对，原登录会话失效。
- [ ] 相同操作编号重发相同请求不重复执行；同编号不同载荷返回 409。
- [ ] 不可写数据卷在操作前阻止写入；操作后发生落盘异常时返回警告而非虚假的未执行。
